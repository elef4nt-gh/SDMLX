The SDMLX Qwen Image Edit 2511 runtime includes local SDMLX changes for:

- Qwen Image Edit 2511 `index_timestep_zero` reference handling
- Qwen Edit Plus `Picture N:` prompt/image prefix handling
- guidance=1.0 single-pass sampling
- Comfy AuraFlow/simple scheduler parity experiments

This directory is bundled as part of the SDMLX release-suite runtime.
